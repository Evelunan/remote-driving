## 工作范围和基线

实施依据为 [改造方案](refactoring-plan.zh-CN.md)。目标为驾驶端、车辆端和统一服务端，包含控制正确性、授权与失效保护、连接生命周期、视频优化、公共模块、打包部署及回归验证。

开始时工作区仅有本次方案相关修改：根 README 的方案入口，以及尚未跟踪的方案文档。保留这些内容，并将其作为改造基线提交。未发现适用的 AGENTS.md。

初始环境为 Linux、Python 3.14.10、uv 0.13.8，无项目虚拟环境；pytest、aioquic、aiortc、NumPy、OpenCV、PyQt6 等运行和测试依赖尚未安装。将建立隔离的项目验证环境，不连接真实车辆或部署公网服务。

已建立项目 .venv，使用 Python 3.12.16；运行依赖通过 `uv export --all-packages --frozen --no-emit-workspace --no-hashes` 导出并安装，与原 uv.lock 对齐。测试工具为 pytest 9.2.0、pytest-asyncio 1.5.0 和 Ruff 0.17.5。当前分支为 refactor/remote-driving，Git 作者仅配置在本仓库。

## 设计调整

- 先在旧目录和既有 12 字节报文上修复控制路由与序号边界，保留固定报文字节测试。身份认证与会话代次随后采用明确版本的新协议实现，不把旧 HELLO 误称为认证。
- 旧应用存在相互冲突的顶层包名，过渡期测试在独立 Python 子进程中导入实际应用，隔离模块缓存与日志目录；采用正式命名空间后迁移为直接测试。测试不连接设备或外部服务。
- 底盘暂缺刹车和反馈契约：`request_safe_stop(reason)` 返回 `StopResult(requested, confirmed, detail)`；现有 ROS/串口适配器只请求零速目标，`confirmed=False`。不能将该结果描述为实车已停车。制动输入当前只请求零线速度和零角速度，不再根据从未更新的“当前速度”计算制动。ROS 转向符号及串口 ×100 编码保持原适配约定，串口物理单位和制动效果仍需硬件方确认。
- 为避免以后重复实现超时逻辑，提前建立 `packages/rd-core`，先提供无设备依赖的控制监护。设备写入串行执行且只保留一个最新待执行目标；监护与设备写入使用不同线程。设备阻塞时清除未执行运动目标并通知独立停车接口，但不能强杀已进入硬件库的调用，也不能据此保证真实停车。车辆控制/媒体进程隔离仍在后续阶段实现。
- 超时进入锁存失效状态，重复包、心跳和无效包不能续期；新会话需先出现中立输入，旧代次的断线和完成回调不能改变新会话。当前旧协议依赖同步时钟检查 32 位时间戳，线上认证、代次及明确的新鲜度字段由后续新版协议完成。`control_timeout_s: 0.3` 仅为模拟默认值，不是已验收的实车安全阈值。
- 旧协议过渡期增加 STOP 类型，发送方必须通过中继连接绑定校验；丢失 STOP 时由车端 watchdog 兜底。输入源失效不续期，原始采样时间贯穿处理、缓存和重复发送。`input_timeout_s: 0.2`、50Hz 同样仅为模拟默认值。界面不再将命令回显换算成“车速”，也不再把往返时间除以二冒充单向延迟。
- 过渡期的失效锁存恢复需要建立新的车端控制会话并重新取得中立输入；仅重连驾驶端不能代替授权恢复。后续可靠注册、控制租约和线上 epoch 将提供完整恢复流程。旧协议阶段不作为实车部署完成态交付。
- 目录迁移为 `apps/{driving,vehicle,server}/src/rd_*`；信令与中继留在服务端内部模块，默认一起启动，`--services` 可分别启用。启动部分失败会逆序清理，运行时任一监听器意外关闭会撤销就绪并停止其他模块。旧协议目前只能显式启用回环开发模式，待认证版协议替换后才开放生产部署配置。
- `rd-core` 提供日志、控制监护、采样及旧线协议；`rd-webrtc` 提供共享连接封装。应用内少量旧模块保留兼容导入，不再各自实现 codec/peer。历史实验移到 examples/legacy，历史 CSV 移到 benchmarks/legacy，不把它们当作本次性能证据。删除代码中的全局代理变量清空行为。
- B06 独立安装目录为 `/tmp/rd-b06-{driving,vehicle,server}`，wheel 位于 `/tmp/rd-b06-dist`；安装依照 uv.lock 导出的第三方约束，未升级已有运行依赖。新增开发依赖组以锁定 pytest、pytest-asyncio、Ruff。wheel 内容检查确认不包含私钥、CSV 日志或 common/config 等通用顶层包。
